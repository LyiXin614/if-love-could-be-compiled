## 1080p 性能采样

独立验收画布，1920×1080，默认 alpha:false 上下文，每档 30 帧预热 + 120 帧采样。测试为第四幕光迹书写与心脏，不含作品页面 DOM 控制器；采样时未进行像素回读。以下为一次最终八档亮度合批版本的结果：

| 画质 | 平均 JS 绘制耗时 | P95 绘制耗时 | 观察到的 RAF 节奏 |
| --- | ---: | ---: | ---: |
| 低 / 2200 | 3.16ms | 4.0ms | 74.2 FPS |
| 中 / 3800 | 4.52ms | 5.7ms | 62.9 FPS |
| 高 / 5600 | 6.32ms | 7.7ms | 51.6 FPS |

合批前同类测量中档约 7.24ms、29 FPS。合批合并了数千次 fill 调用；本机测量显示改善。此结果不能推断所有 Windows 笔记本都能达到同样帧率，也不是整页和所有场景的稳定 FPS 保证。后续对截图稳定落点、终章字符和显式 Canvas 初始状态的小修未另做全套性能基准。
