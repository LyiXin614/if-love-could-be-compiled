# 如果浪漫可以被编译 · V2.0

**If Love Could Be Compiled — 一封以粒子、时间与代码写成的可执行情诗。**

> 在理性的尽头，让一行代码，长成一整个宇宙。

V2 在原有项目上增量升级，保留六幕顺序、中文原诗、数学心形、全部交互与本地运行方式。完整演出 **172 秒（2 分 52 秒）**。没有第三方运行时依赖、外部素材、网络字体或 API Key。V1 源码包与图片仍留在 outputs 根目录；本次交付放在 `outputs/v2/`。

## Windows 启动

安装 Node.js 18 或更新版本。在项目目录打开 PowerShell：

```powershell
node server.mjs
```

用 Chrome 打开 **http://127.0.0.1:5173**。也可以双击原有 `start.cmd`；有 npm 时可执行 `npm start` / `npm run dev`，**无需 npm install**。

不要双击 index.html，ES Module 与源码 fetch 需要本地 HTTP 服务。Ctrl+C 停止服务。服务器仅监听 127.0.0.1。

如果旧版已占用 5173，可先关闭旧服务；也可以临时更换端口：

```powershell
$env:PORT = '5174'
node server.mjs
```

此时访问 http://127.0.0.1:5174。本次验收使用 5174，以保留用户正在 5173 上运行的解压版 V1。

## 六幕与节奏

| 幕次 | 时长 | V2 画面与阅读安排 |
| --- | --- | --- |
| 初始化 | 18 秒 | 大字号玻璃终端、输入与扫描光；最后将未定义的代码逐字解码为原有中文诗句 |
| 异常 | 22 秒 | `heartbeat = Infinity;` 解码；稀疏银蓝色初醒之心；“直到你成为唯一的例外”由光点聚成笔画 |
| 编译 | 28 秒 | 粒子从真实非空代码字位出生；花瓣与星屑流场；两组原诗依次粒子成字并稳定阅读 |
| 心动 | 34 秒 | 炽热双拍；10 秒开始蓄势，12–12.6 秒静默，随后爆发、旋涡与回归；23 秒之后轮廓光迹书写核心两句 |
| 诗行 | 34 秒 | 左侧 20px 代码情诗，右侧永恒心脏及双轨光点；20 秒后代码淡去，两组中文诗句从空间深处靠近、停留、远去 |
| 继续 | 36 秒 | 心脏稳定→3–10 秒化为中文粒子告白→10–19 秒阅读→19–27 秒回归心脏→稳定终镜与 BUILD SUCCESSFUL |

结尾不重复破碎重生。演出时钟停止在 02:52，环境时钟继续驱动心跳、双轨光点和星光。

## 操作与原功能

底栏提供开始、暂停、继续、上一幕、下一幕、直接选幕、备选诗句、音效开关、画质、全屏和定格。结尾保留“再运行一次 / 阅读源代码 / 定格这一刻”。

| 快捷键 | 功能 |
| --- | --- |
| Space | 开始 / 暂停 / 继续；按钮聚焦时遵循原生空格行为 |
| ← / → | 上一幕 / 下一幕 |
| R | 重播 |
| P | 循环四条备选诗；切换幕次恢复原诗 |
| S | 定格 / 恢复 |
| F | 全屏；原生浏览器也可使用 F11 |

鼠标移动带来轻微倾斜、光轨视差与局部粒子排斥。点击心脏增加一次发光、扩散和能量环；有 **0.8 秒冷却**，不创建新循环。第四幕 10–22 秒和第六幕 3–27 秒保护主剧情，不接受额外点击脉冲。

声音默认静音；手动启用才创建 Web Audio 上下文。仅有本地合成短音，无外部音乐。画质沿用高 / 中 / 低 **5600 / 3800 / 2200** 个主体粒子。自动模式参考硬件与持续帧间隔降档。显示 DPR 上限 1.75，低档 1。

定格时：时间冻结、指针归零、额外点击脉冲清零，文字动画取完整可读的稳定落点；粒子成诗保留笔画光尘，光迹书写保留轮廓余辉。编译预设里的代码消散是有意的叙事构图。普通定格也保留当前形态；若希望完整心形，请选 B / C / 绽放重生 / 永恒之心。

PNG 不包含任何控制器。若下载受策略限制，页面提示可在定格后全屏使用系统截图。按 S 或“返回 · S”恢复进入定格前的播放状态。

## 技术实现与边界

**时间与暂停。** 仍只有 main.js 的一条无限 RAF。幕次效果使用 `timeline.state.local`；心跳、星光使用 `visualTime`。暂停时两者冻结，绘制键不变则不重复渲染。跳幕时将视觉时钟同步到总演出时间，清除点击脉冲和指针；重播不重新注册监听器。无每幕 setInterval 或粒子速度积分积累。

**文字排版。** 保留 1600×900 逻辑空间，按角色分别设置字号。文字先经过 measureText，再换行或有限缩小；第五幕重新分配左侧 735px 区域。中文主诗 32–42px，章节 36px，代码 20–22px，辅助信息通常 14–17px。长诗允许增行；如果把原稿改成很长段落，仍应检查该幕可用高度。

**四种文字。** 解码用稳定哈希扰动和逐字符锁定，每秒约九次局部扰动；粒子成诗用文字像素目标与错开延迟；光迹书写追踪二值字形的真实闭合轮廓，包含内孔，抬笔后进入下一轮廓，**不宣称真实中文笔顺**；空间文字用缩放、纵深位移、入场景深及退场光尘，阅读阶段保持稳定。所有效果最后叠加清晰文字。

**心形与形态。** 保留原三角参数方程与高斯双峰心跳。HeartMorphSystem 由时间返回形态，不持有不断积累的速度；爆发方向来自固定种子，经历连续径向扩散、角度旋转和阻尼式回归。永恒形态有不同角度、不同转速的两条椭圆轨道与十个光点。

**心诗变形。** 最终中文由共享字形掩码生成目标点，直接接收原心脏粒子；阅读后沿连续弧线回归原心形。稳定终镜恢复双轨心脏，不重复高潮。

**性能。** 主粒子坐标与颜色分桶保存在预分配 TypedArray，按四种颜色、八档亮度最多 32 次路径填充；少量粒子使用缓存光晕精灵。字形只在首次出现或样式变化时采样，缓存上限 24 条。光迹完成后直接绘制清晰字层，停止逐点追踪。画质变化重用点集，导出使用同一模块。

## 测试与已知限制

```powershell
node --test tests/*.test.js
```

浏览器验收台：启动服务后打开 `/tests/browser.html`，运行画布回归和性能采样，或选择七种确定性中间帧。回归先做绘制与像素回读预热，避免首次回读触发浏览器后端切换带来的颜色舍入差异；之后比较重复帧与跨场景预设的哈希。性能采样另外新建与作品相同的默认上下文，不使用像素回读上下文。

实际结果、回归操作与未验证项目见 `outputs/v2/验收记录.md`。一次机器上的绘制耗时和采样 FPS 不代表所有 Windows 笔记本表现。尚未做多台真机、数小时内存趋势、系统截图策略与独立 Chrome 全屏的完整验收；建议比赛前在目标 Chrome 全屏完整预演。画布针对横屏 16:9；移动竖屏会压缩艺术画面，不作为主要展示目标。
